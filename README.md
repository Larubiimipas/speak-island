# Speak Island

Game petualangan 3D untuk latihan berbicara bahasa Inggris tingkat pemula.

- Jelajahi pulau, temui 6 warga, dan selesaikan quest percakapan.
- Ucapan dinilai otomatis per kata (butuh Google Chrome dan izin mikrofon).
- Ilustrasi karakter dibuat dengan Canva.

Buka `index.html` lewat alamat HTTPS (misalnya GitHub Pages) agar mikrofon bisa dipakai.
